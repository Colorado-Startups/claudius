Purpose

This repo is the Soul-Craft fork of Colorado-Startups/claudius, the Claude pack for Git Crafter (README.md, read 2026-11-25). The pack holds Claude Code templates, Quality tabs and Process maps for a repo that agents drive from the Claude desktop app.

Upstream is an outside public repo. We use the Claudius templates as they are and contribute upstream as an ordinary outside contributor (owner, 2026-11-25; issue 73).

The fork is only a vehicle for pull requests. It keeps no features of its own and publishes no releases of its own.

How it works

The fork never merges, tags or changes settings upstream. The upstream maintainers decide what lands (issue 73).

In the fork, a branch merges only to carry a change toward upstream. It waits for green CI and a review at the head commit, then goes by REST with the head SHA as its guard (AGENTS.md). Nothing is pushed to main.

The owner's decision, made 2026-11-25

We do not run a diverging fork.

We use the Claudius templates as they are and contribute upstream as an outside open-source contributor. The fork is a pull-request vehicle only: no releases of its own, no maintained distribution, no extra features kept on it.
